First post — how this garden works

A short note on how pages get added here, for future me.

Every page on this site is a plain HTML file. To publish a new blog post, drop a file like blog/my-post.html into this folder, link to it from the blog index, push to main, and the GitHub Action builds and deploys the site automatically.

Drafts live outside this repository and only get moved in when they're ready for the world — so main always reflects what's actually published.
