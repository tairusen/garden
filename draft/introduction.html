Introduction

plain text

Hello. This is Tairusen's Garden — a personal site built like the engineering software of the late 2000s: square corners, flat panels, borders that tell you exactly where things begin and end.

There's no framework here. Plain HTML files, one stylesheet, a few lines of JavaScript. The aesthetic borrows its colors from open-source dark themes: #1e1e1e backgrounds, a single blue accent, and green where things grow.

Why "Garden"?

Because a garden is never finished. You plant things, some of them take, some of them don't, and the moss grows on whatever you stop paying attention to. This site works the same way.

Things to try

The games folder in the explorer holds small toys built in plain HTML — try the Number Guesser to see how a link works inside the pane.
