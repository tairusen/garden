Introduction

plain text

Hello. This is Tairusen's Garden — a personal site built like the engineering software of the late 2000s: square corners, flat panels, borders that tell you exactly where things begin and end.

There's no framework here. One HTML file, one stylesheet, a few lines of JavaScript. The aesthetic borrows its colors from open-source dark themes: #1e1e1e backgrounds, a single blue accent, and green where things grow.

Why "Garden"?

Because a garden is never finished. You plant things, some of them take, some of them don't, and the moss grows on whatever you stop paying attention to. This site works the same way.

Things to try

The Apps & Games section in the side pane holds small toys built in plain HTML — try the Number Guesser to see how a "follow link" works inside the page.

AI Policy

plain text

Transparency statement, in plain language:

Writing. All opinions, decisions, and final text on this site are mine. AI tools were used as an editor and rubber duck — for brainstorming structure and debugging code — not as an author.

Code. Some JavaScript and CSS on this site was written with AI assistance. It is reviewed, understood, and modified by me before it ships. There is no code on this site I can't explain.

Artwork. No AI-generated images are used. The only "art" here is CSS.

This policy covers the site itself. Individual posts or projects will state their own usage where relevant.
